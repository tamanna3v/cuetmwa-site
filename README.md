# চুয়েট চিকিৎসা সহায়তা কল্যাণ সমিতি — ওয়েবসাইট

CUET Medical Welfare Association (CUETMWA)-এর ওয়েবসাইট — https://cuetmwa.org

- `index.html` — পুরো সাইট (CSS, JS ও লোগো ভেতরেই আছে)

ট্যাব: আমাদের কথা · সদস্য ও অনুদান · সদস্যপদ নবায়ন · নোটিশ ও আপডেট · যোগাযোগ

তথ্য: সদস্য তালিকা ও অনুদান তালিকা, জুন ২০২৬ পর্যন্ত।

## যা পরে বদলাতে হবে
- ডোরাকাটা বাক্সগুলো ছবির প্লেসহোল্ডার (`class="ph"`) — আসল ছবি বসাতে হবে
- বিকাশ/নগদ/ব্যাংক নম্বর ও কমিটির তথ্য — "যোগ করা হবে" (`class="tbd"`)
- নতুন নোটিশ যোগ করতে `index.html`-এর `NOTICES` তালিকায় একটা এন্ট্রি যোগ করুন

সাইটটি GitHub Pages থেকে চলে (branch `main`, root)।
